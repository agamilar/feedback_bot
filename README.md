# Feedback / Support Bot

Простой Telegram-бот обратной связи: пользователь пишет боту в личку,
сообщение пересылается в ваш чат (админский), вы отвечаете реплаем —
ответ уходит пользователю. Поддерживает текст, фото, документы, голосовые
и т.д. (используется `copy_message`, так что медиа проходит без потерь).

## Как это работает

1. Пользователь пишет боту → сообщение форвардится в `ADMIN_CHAT_ID`,
   под форвардом добавляется строка "От: Имя (@username)".
2. Связка `id пересланного сообщения → id пользователя` сохраняется в
   SQLite (`data/feedback.db`), чтобы бот знал, куда отправлять ответ.
3. Вы (или другой админ, если это группа) делаете **Reply** на пересланное
   сообщение — бот копирует ваш ответ пользователю.

## Установка

```bash
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

В `.env` укажите:
- `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather)
- `ADMIN_CHAT_ID` — ваш Telegram user ID (узнать у [@userinfobot](https://t.me/userinfobot))
  или ID группы, если хотите отвечать командой. Если это группа —
  добавьте туда бота и отключите privacy mode у @BotFather
  (`/setprivacy` → Disable), иначе бот не увидит ваши реплаи.

Запуск:

```bash
python bot.py
```

## Деплой на Bothost

Учитывая, что у Bothost нет публичного входящего адреса, бот работает
через polling (`start_polling`), а не через webhook — это уже заложено
в коде, ничего дополнительно настраивать не нужно.

- Файл БД (`data/feedback.db`) переживает редеплой, если у вас настроена
  persistent-директория `/app/data` — путь в `.env` (`DB_PATH`) можно
  указать как `/app/data/feedback.db`, как в вашем проекте Mora.
- Секреты (`BOT_TOKEN`, `ADMIN_CHAT_ID`) — только в `.env`, не в коде.

## Возможные доработки

- Несколько админов / распределение по темам (topics) в супергруппе
- Категории обращений (кнопки: вопрос / баг / предложение)
- Автоответ в нерабочее время
- Экспорт истории обращений в Excel (openpyxl, как в Mora)
